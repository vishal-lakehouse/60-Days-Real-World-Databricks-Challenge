# 🏢 Business Scenario

The Marketing Team wants to answer questions like:

- Who are our most valuable customers?
- Which customers purchase most frequently?
- What is the average customer spending?
- Which states generate the highest customer revenue?
- How many repeat customers do we have?

Currently, this requires joining multiple datasets every time.

Your responsibility is to create a **Customer Analytics Gold** table that provides all customer metrics in one place.

## Task 5

Calculate Customer Lifetime Value (CLV).

Use:

```
CLV = Total Revenue
```

*(For this project, assume Customer Lifetime Value is equal to the total revenue generated by the customer.)*

Apply Window Functions.

