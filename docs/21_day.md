# 🏢 Business Scenario

Olist has thousands of sellers across Brazil.

The Marketplace Team wants to answer questions like:

- Who are the top-performing sellers?
- Which sellers generate the highest revenue?
- Which sellers sell the most products?
- Which states have the highest-performing sellers?
- What is each seller's average order value?

Instead of joining multiple Silver tables every time, the company wants a single Gold table containing seller performance metrics.

Your responsibility is to create a **Seller Performance Analytics Gold** table.
